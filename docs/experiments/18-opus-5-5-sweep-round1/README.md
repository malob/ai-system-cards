fifth card (anthropic/claude-opus-5-5 — Claude Opus 5.5, 230pp, same Google-Docs

**Method:** the two-check round-G design (experiments 09 and 14), re-rulebooked
for this card (`rulebook.md` here): 8 triple-pane comparators over all 223
content pages (PDF render vs md slice vs served production HTML, zoom crops for

**Result:** 11 agents, 235 units (223 pages + 12 files), 215 clean, 20

prose underline and `th`-vs-`td` header semantics are below T1's token
